# 相机内参与外参标定指南

> 适用硬件：海康 MV-CS016-10UC（160 万像素，1440×1080 原生），镜头 6mm，传感器 1/1.8" 级别。
> 当前系统工作分辨率：**640×640（传感器中心 ROI 裁剪）**，标定与使用分辨率必须一致。

---

## 1. 镜头视场角（先了解再标定）

1/1.8" 传感器尺寸约 7.2×5.4mm（像素约 3.45μm），6mm 焦距：

| 分辨率 | 水平 FOV | 垂直 FOV | 说明 |
|---|---|---|---|
| 1440×1080（全幅） | ≈45° | ≈34.5° | 传感器全读出 |
| **640×640（当前 ROI）** | **≈21°** | **≈21°** | 中心裁剪，视场角大幅缩小 |

> ⚠️ **重要**：640×640 模式下视场角只有约 21°，属于窄视场。检测距离范围受
> 「视场能否容纳目标 + 目标像素尺寸是否在模型训练分布内」双重约束。
> 若实测发现近距离/远距离漏检严重，优先考虑改回更大 ROI（如 1024×1024，FOV≈33°）。

装甲板（步兵 135×55mm）在 640×640、fx≈1833 下的像素尺寸：

| 距离 | 宽(px) | 高(px) | 占画面宽 |
|---|---|---|---|
| 1.0m | 247 | 101 | 38.6% |
| 1.5m | 165 | 67 | 25.8% |
| 2.0m | 124 | 50 | 19.3% |
| 3.0m | 82 | 34 | 12.9% |
| 4.0m | 62 | 25 | 9.7% |
| 5.0m | 49 | 20 | 7.7% |

## 2. 内参标定

### 2.1 标定板准备（关键：匹配 6mm 短焦大视场）

- **首选 ChArUco 板**（OpenCV 官方 `charuco` 目标，ROS camera_calibration 原生支持），
  对短焦广角畸变大的镜头比棋盘格更稳（角点带 ID，遮挡/边缘也能用）。
- 棋盘格建议 **9×7 内角点、格宽 40mm 以上**，板子尽量大（≥ A3），
  A4 小棋盘在 1.5m 外角点太小、标定精度差。
- 板子必须**平整**（亚克力/铝板），纸打印贴板会产生波纹误差。
- 打印后实测格宽（卡尺），标定参数里填真实值。

### 2.2 采集过程（一次采够，避免重复返工）

```bash
# 1. 只起相机（标定时不需要检测/跟踪）
cd ~/yami && source /opt/ros/foxy/setup.bash && source install/setup.bash
ros2 launch hik_camera hik_camera.launch.py
# 若标定 640×640 模式：确认 node_params.yaml 里 width: 640 height: 640

# 2. 启动标定 GUI
ros2 run camera_calibration cameracalibrator \
  --size 9x7 --square 0.04 --pattern chessboard \
  --ros-args -r image:=/image_raw -r camera:=/camera_info
```

采集要点（GUI 右上角进度条 X/Y/SIZE/SKEW 全绿即可点 CALIBRATE）：

- **距离覆盖**：0.5m、1m、1.5m、2m、3m、4m 各采集若干张（覆盖实际工作距离！）。
- **姿态覆盖**：每距离下板子绕 X/Y/Z 各 ±20~30° 倾斜；图像四角与中心都要有板子出现。
- **数量**：40~60 张，宁可多不要少；每张板子占画面 20%~60%。
- 移动板子要慢、稳，避免运动模糊；曝光时间短（当前 6000μs 可以）。
- 标定过程中相机位置不动、**分辨率/ROI 不改**。

### 2.3 标定与保存

1. GUI 里点 **CALIBRATE**，等待结算（几秒~十几秒）。
2. 看 **epx/epy（重投影误差）**：< 0.3px 优秀，< 0.5px 可用，> 0.8px 需重采。
3. 点 **SAVE** → 生成 `calibrationdata.tar.gz`；点 **COMMIT** → 参数直接写入
   `src/rm_vision_bringup/config/camera_info.yaml`（当前正在使用的文件）。
4. 检查 camera_info.yaml：`image_width/height` 必须等于当前相机输出（640×640），
   主点 `cx,cy` 应接近图像中心（320±40, 320±40），偏差过大说明板子覆盖不均需重采。

### 2.4 640×640 ROI 模式的特殊注意

- 相机 ROI（`width/height/offset` 居中裁剪）**只改变主点位置，不改变焦距**。
  若手上有全幅（1440×1080）标定结果，可直接换算：
  `cx_new = cx_full - (1440-640)/2`，`cy_new = cy_full - (1080-640)/2`，fx/fy/k 不变。
  （本项目当前 camera_info.yaml 即按此从 1280×960 标定换算得到。）
- 若换了 ROI 大小，必须重新标定或重新换算主点，**不能直接复用旧 camera_info**。

### 2.5 畸变系数自查（针对当前 5 参数模型）

当前 k3=-11.27 数值偏大，属于强畸变模型。自查方法：

- 若 k3 的绝对值比 k2 大一个数量级以上，且标定时板子没有覆盖图像**四个角**，
  很可能是外推过度拟合 → 建议**重采**（重点补四角姿态）。
- 实际验证：用 `camera_calibration` 的 rectify 视图看直线是否直；
  或用 PnP 解算已知尺寸装甲板，距离 1~4m 测距误差应 <5%。

## 3. 外参标定（相机 → 云台/机器人坐标）

外参在本项目中的位置：`src/rm_vision_bringup/config/launch_params.yaml` 的 `odom2camera`
（`xyz` 平移 + `rpy` 旋转），由 robot_state_publisher 生成 TF：
`odom → gimbal_link → camera_link → camera_optical_frame`。

### 3.1 坐标系约定（REP-103）

- 相机光学系：x 右、y 下、z 前。
- 云台系（odom）：x 前、y 左、z 上（本仓库约定）。

### 3.2 标定过程（先粗后精）

**第一步：粗测（卷尺 + 水平仪）**

1. 云台回中、调平，记录当前云台 yaw/pitch。
2. 测量相机光心相对云台转轴的三维偏移（沿车体 x/y/z）。
3. 测量相机朝向与云台前向的夹角（水平仪贴镜头前口测 pitch；yaw 看安装基准面）。
4. 填入 `launch_params.yaml`：
   - `odom2camera.xyz`：相机光心在云台系中的位置（约 ±0.1m 量级）。
   - `odom2camera.rpy`：云台系→相机系的欧拉角（roll/pitch/yaw，rad）。
   - 典型前视安装：roll≈0，pitch≈0（相机光轴水平），yaw≈0。

**第二步：精调（目标重投影验证，最实用）**

1. 把一块已知尺寸的装甲板（或 ArUco/ChArUco）放在相机正前方已知距离 d（如 2m）、
   已知高度处，记录真实位置（相对云台基座）。
2. 运行管线：`ros2 topic echo /tracker/target`（或 `/detector/armors` 的 pose），
   对比解算位置与真实位置：
   - x 偏差大 → 调 `odom2camera.xyz` 的 x（前向偏移）；
   - y 偏差大 → 调 y（左右偏移）与 yaw；
   - z 偏差大 → 调 z（高度）与 pitch。
3. 换 2~3 个距离/角度复测，直到位置误差 < 3cm、yaw 误差 < 2°。

**第三步（可选）：手眼标定**

若追求高精度，用云台扫过已知空间点（标定板固定，云台多姿态拍摄），
解 AX=XB 得到相机到云台转轴的完整外参。对 3V3 自瞄，
第二步的逐项微调通常已足够（外参误差主要影响远距离角度，而非近距离命中）。

### 3.3 验证清单

- [ ] `ros2 run tf2_ros tf2_echo odom camera_optical_frame` 的平移/旋转符合实测。
- [ ] 目标静止时 `/tracker/target` 的 position 稳定（抖动 < 2cm）。
- [ ] 1~4m 多个距离实测位置误差 < 3cm。
- [ ] 云台转动时目标 yaw 变化连续无跳变。

## 4. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 标定板角点检测不到 | 板子小/距离远/反光 | 换大板、调曝光/增益、加柔光 |
| epx/epy > 0.8px | 采样覆盖不足/板子翘曲 | 按 §2.2 重采，重点补边缘姿态 |
| 主点偏离中心 >40px | 采样偏一侧 | 重采，保证板子均匀覆盖画面 |
| 换 ROI 后位姿全错 | 内参未按新分辨率换算 | 见 §2.4 重新换算/标定 |
| 远距离误差大 | 外参 pitch/yaw 有残差 | 用远距离目标精调 rpy（§3.2 第二步） |
